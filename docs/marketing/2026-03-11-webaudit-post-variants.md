## How to use this file

This file is the copy bank for the 16 publishable posts in the launch-month campaign.

- Use **Option A** when you want the safer, clearer, proof-led version.
- Use **Option B** when you want a sharper, more opinionated, more conversational version.
- Keep the date, asset, CTA, and target URL aligned with the schedule unless you intentionally reschedule the campaign.
- For posts marked `no-link post`, keep the post native and do not add a URL unless you intentionally convert it into a click-driving post.
- On X specifically, keep the copy short and let the screenshot or GIF carry more of the explanation.
- In the first half of the month, prefer plain outcomes like pages losing clicks, likely causes, and next fixes before introducing internal labels.
- If you manually edit and publish an X post, update that post here and use it as the style reference for the following X posts only.
